# Integration

Phinary pools are ordinary Uniswap v4 pools with a hook, so integrating uses the standard Uniswap contracts: V4Quoter for quotes, UniversalRouter for swaps and Permit2 for approvals. The hook adds a few read functions for market data.

## Market tracks

Every market belongs to one of four tracks: ETH or SOL, 1 or 15 minutes long. All of them live on the one hook and share its `marketCount`, so ids of different tracks interleave. Three ways to tell which track a market is on:

- **`gatekeeper.schedulerOf(marketId)`** returns the scheduler that opened it, or `address(0)` for an id the gatekeeper never created. This is the on-chain answer, and one multicall covers a whole list of ids.
- **The `MarketOpened` event.** Each scheduler emits `MarketOpened(marketId, slot, caller, budget, strikeCents)` right after the hook's `MarketCreated`, in the same transaction. The address that emitted it is the track. Trust it only when that address is in `gatekeeper.schedulers()`: anyone can deploy a copy of `MarketScheduler` behind a fake gatekeeper, and its event would name a real market id ([Events](/integration/events#marketopened)).
- **The symbol**, matched exactly against `ticker + "UP"` and `ticker + "DOWN"` from each scheduler's `config()`. Never match a prefix (`ETH` is a prefix of `ETH15M`) or an expiry (at a quarter hour all four tracks expire together).

To list a track's recent markets without scanning every id, read `scheduler.marketOfSlot(slot)` for the last few slots, where `slot = block.timestamp / period`. A skipped slot returns 0. `@phinary/swap-sdk` wraps all of this as `readTracks`, `recentTrackMarketIds`, `schedulerOfMarkets` and `classifyBySymbol` (<Source path="packages/swap-sdk/src/tracks.ts" />).

## Routing

Uniswap's hosted routing skips hook-priced pools that hold no liquidity unless the hook is allowlisted. Phinary therefore quotes with V4Quoter directly, and runs a fork of the Uniswap web app (`interface-patches/`) that answers USDC to YES or NO requests in the page and builds the UniversalRouter transaction locally. Every other pair still goes through Uniswap's normal routing.
