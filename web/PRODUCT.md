# Phinary
<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
An onchain ETH binary prediction market on Uniswap v4. The dashboard lets visitors compare actual markets, connect a wallet, and open the existing purchase flow. This surface is an operating interface with a compact product introduction.

## Users
Hackathon demo visitors and users exploring the testnet markets. Broader production audience remains undecided.

## Capabilities and Constraints
Unichain Sepolia. Current connection supports real market reads, wallet connection and UP purchases. DOWN navigation opens an existing preview with the current unsupported-purchase notice. History, volume and settlement history are unavailable; never fabricate them. Protocol, pricing, API, SDK and contracts stay unchanged. Scope: Markets body, Market Detail (`/market/[id]`) and the shared header. Market Detail extends the same approved visual system; the shared header remains unchanged in this extension. Sell and Claim remain disabled, and DOWN is preview only. Position holdings come from real token balances; average cost and unrealized P&L remain N/A without cost-basis data. Chart history, recent trades and unavailable pool addresses remain explicitly unavailable. This scope expansion adds no API or protocol capability.

## Brand Commitments
Phinary cyan/violet Phi mark and text wordmark (updated user reference). English UI, UP / DOWN terminology. The user-approved reference is a near-black financial interface with violet atmospheric artwork and compact market tables.

## Evidence on Hand
README.md, DESIGN.md, current data hooks and the approved Markets screenshot and prompt in the conversation. Data and transaction behavior are authoritative over illustrative values in the reference.
